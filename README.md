# animations-trash

> **动画实验垃圾桶** — 随手丢动画 Demo 的仓库，不是产品、也不是脚手架。

## 状态

- **Legacy / 学习用**：内容多为个人试验与练习，可能过时、不完整，或依赖本地临时改动。
- **不建议当模板**：请勿 fork 当作新项目起点；需要模板请用官方 `create-next-app` 或你自己的脚手架。

## 说明

本仓库基于 [Next.js](https://nextjs.org/)（`create-next-app`）搭过一点本地实验环境。若仍要本地跑着玩：

```bash
pnpm install   # 或 npm / yarn
pnpm dev
```

打开 [http://localhost:3000](http://localhost:3000)。
